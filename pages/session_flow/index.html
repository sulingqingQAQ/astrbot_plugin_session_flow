谁在往上下文里塞东西

        
按插件统计每轮被塞进请求的内容有多少字（只统计记到的“注入”）。“内核 / 更早”是会话流看到请求时就已经在的；

导出时屏蔽哪些内容

        
在这里设好的规则，导出（单轮、一整页、搜索结果）时会把匹配的那一段整段删掉，不留占位，
          文件开头只写一句“有 N 段被屏蔽”。默认一条规则都没有，也就是什么都不屏蔽。号码、群名不会被自动打码。
          名字可以写注入块名、来源插件、工具名，支持 * 通配；提问、回复、思考、system prompt 没有名字，只能整种屏蔽。

        

        

          
          
          
          
          
        

        

      

      

        
运行诊断

        
插件自己的运行日志和状态：钩子触发次数 / 耗时 / 报错、后台任务、库状态、最近几十轮的摘要、日志尾巴。
          不含聊天内容，会话 ID 默认打码。插件出问题时点「下载诊断包」，把文件发给帮你看的人。
